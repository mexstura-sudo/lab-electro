# Лаборатории по электротехнике

Интерактивные страницы к курсу «Электротехника и электроника» (Иркутский техникум машиностроения им. Н.П. Трапезникова). Работают в браузере на интерактивной доске и на телефоне, без установки.

| Лаборатория | Темы | Ссылка |
|---|---|---|
| Переменный ток | 1.4 «Цепи переменного тока» (пары 11–12 СП) | `ac-current/` |
| Диод и выпрямитель | 21 «p-n-переход, диоды, обозначения», 22 «Выпрямители» | `diode-rectifier/` |

## Как включить сайт (GitHub Pages)

Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
Через 1–2 минуты сайт будет доступен по адресу `https://mexstura-sudo.github.io/lab-electro/`, лаборатория — `https://mexstura-sudo.github.io/lab-electro/diode-rectifier/`.

## Как добавить новую лабораторию

Создайте папку с `index.html` внутри и добавьте ссылку в `index.html` и в таблицу выше. Каждая страница — один самодостаточный HTML-файл (стили и скрипты внутри, внешние только шрифты Google Fonts).
