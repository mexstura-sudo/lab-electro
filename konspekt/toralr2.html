ЛР № 2. Смешанное соединение резисторов

Один резистор последовательно, два — параллельно. Меряем все токи и напряжения и проверяем оба закона Кирхгофа.

1. Цель и вариант

Цель: рассчитать смешанную цепь R1 + (R2 ∥ R3), измерить все токи и напряжения, проверить законы Кирхгофа.

Вариант — номер в журнале: R1, R2, R3 при напряжении 12 В. Маршруты: А — Proteus, Б — вживую, В — браузер, вкладка «Смешанная».

Осторожно

Каждый перенос амперметра — при выключенном блоке питания. Ток до 150 мА: предел 200 мА, щуп в гнезде mA. Резисторы малых номиналов при 12 В греются — не трогать под напряжением.

2. Расчёт до опыта

Сначала сворачиваем цепь, потом разворачиваем:

  1. R23 = R2 · R3 / (R2 + R3)
  2. Rэкв = R1 + R23
  3. I = U / Rэкв
  4. U1 = I · R1, U23 = I · R23
  5. I2 = U23 / R2, I3 = U23 / R3

Образец, вариант 4: R1 = 100, R2 = 330, R3 = 68 Ом, U = 12 В.

R23 = 330 · 68 / 398 = 56,4 Ом; Rэкв = 100 + 56,4 = 156,4 Ом; I = 12 / 156,4 = 76,7 мА.

U1 = 0,0767 · 100 = 7,67 В; U23 = 0,0767 · 56,4 = 4,33 В.

I2 = 4,33 / 330 = 13,1 мА; I3 = 4,33 / 68 = 63,6 мА.

3. Измерения

Соберите сначала токовую цепь: блок → амперметр → R1 → узел → R2 и R3 → узел → блок. Потом вольтметры: V1 на R1, V23 на параллельный участок.

Запишите шесть величин: Uист, U1, U23 (вольтметром) и I, I2, I3 (амперметром в разрыве каждой ветви). Rэкв эксп = Uист / I — сравните с расчётным.

4. Законы Кирхгофа

Первый закон: сколько тока втекло в узел, столько и вытекло: I = I2 + I3. Больший ток — в ветви с меньшим сопротивлением.

Второй закон: в замкнутом контуре сумма падений напряжения равна ЭДС: U1 + U23 = Uист.

Если I2 + I3 не совпало с I на 5–10 % — амперметр немного меняет цепь (у мультиметра на пределе 200 мА сопротивление шунта — единицы ом). Запишите это в выводы как причину расхождения.

В машине

Почти любая цепь в машине — смешанная: две фары параллельно, а последовательно с ними провод и контакты выключателя. Отопитель: резисторный блок последовательно с мотором, а переключатель закорачивает его части. В лаборатории под таблицей есть блок «Отопитель» — посмотрите токи на трёх скоростях.

5. Маршруты А и В

Proteus: RES ×3, BATTERY (Voltage = 12), DC AMMETER ×3 (Milliamps), DC VOLTMETER ×2. A — до R1, A2 и A3 — в ветвях. V1 — на R1, V23 — на параллельный участок. Запустить ▶, записать все шесть показаний.

Браузер: впишите номер варианта, «Показать приборы» — шесть показаний в таблицу. Рядом — проверка: Rэкв теор, Rэкв эксп, I2 + I3, U1 + U23.

6. Выводы и защита

Шаблон выводов:

  1. Rэкв по расчёту … Ом, по опыту … Ом — расхождение … %.
  2. Первый закон Кирхгофа выполняется: I = … мА, I2 + I3 = … мА.
  3. Второй закон Кирхгофа выполняется: Uист = … В, U1 + U23 = … В.
  4. Больший ток — в ветви с меньшим сопротивлением (R… = … Ом).

В отчёт: схема, расчёт, таблица измерений, проверки законов Кирхгофа, выводы. К ЛР № 3 рассчитайте для своего R мощность P = U² / R при 2, 4 … 12 В.

Словарик

  • Узел — точка, где соединяются три провода и больше.
  • Контур — замкнутый путь по цепи.
  • Rэкв — эквивалентное (общее) сопротивление цепи.
  • Смешанное соединение — часть элементов последовательно, часть параллельно.

Смешанное соединение

Смешанное соединение резисторов: порядок расчёта. Резисторный блок вентилятора отопителя.

  1. Смешанное соединение — часть элементов включена последовательно, часть параллельно.
  2. Порядок: найти параллельные группы → заменить эквивалентом → сложить последовательные → Rэкв → общий ток I = U / Rэкв → напряжения участков → токи ветвей.
  3. Пример: R1 + (R2 ∥ R3) = R1 + R2·R3 / (R2 + R3).
  4. В машине: две фары параллельно, а последовательно с ними провод и контакты выключателя. Резисторный блок отопителя: на 1-й скорости последовательно с мотором два резистора, на 2-й — один, на 3-й — без резисторов.
  5. Проверка расчёта: сумма токов ветвей равна общему току; сумма напряжений на участках равна напряжению источника.

Проверь себя

Сначала ответьте сами — в тетради или вслух. Потом нажмите на вопрос, чтобы увидеть ответ.

1Сформулируйте первый закон Кирхгофа.

Сумма токов, втекающих в узел, равна сумме вытекающих.

2Сформулируйте второй закон Кирхгофа.

В замкнутом контуре сумма ЭДС равна сумме падений напряжения: ΣE = ΣI·R.

3Как рассчитать Rэкв цепи R1 + (R2 ∥ R3)?

Rэкв = R1 + R2 · R3 / (R2 + R3).

4В какой ветви ток больше — с 330 или с 68 Ом?

С 68 Ом: напряжение на ветвях одно, ток больше там, где сопротивление меньше.

5Где в машине смешанное соединение?

Отопитель (резисторы и мотор), фары с проводом и контактами выключателя.
